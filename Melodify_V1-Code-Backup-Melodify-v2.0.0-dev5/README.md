# Melodify - Music & Offline Player

**Melodify** is a modern, privacy-respecting, ad-free music and offline audio player for Android built with Kotlin and Jetpack Compose. It offers seamless online discovery, offline music management, synchronized karaoke-style lyrics, and an advanced audio engine.

## ✨ Features

- 🎧 **Ad-Free Streaming:** Discover and play trending tracks without commercial interruptions.
- 📂 **Offline Audio Player:** Play your local device audio files anywhere, completely offline.
- 🎤 **Real-Time Synced Lyrics:** Karaoke-style lyrics synchronized word-by-word with the track.
- 📱 **Background & Lock Screen Controls:** Full media session integration with lock screen art and playback controls.
- 🎚️ **Audio Engine & Haptic Bass:** Equalizer presets, dynamic bass boost, and tactile haptic feedback.
- 🎨 **Modern AMOLED UI:** Sleek, minimal dark theme designed for ease of use and battery efficiency.
- 🔒 **Privacy-First:** Zero ads, zero trackers, 100% libre and open source.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose & Material 3
- **Audio Engine:** AndroidX Media3 (ExoPlayer)
- **Database:** Room Persistence Library
- **Stream Extraction:** NewPipe Extractor
- **Networking & Images:** OkHttp, Coil
- **Build System:** Gradle Kotlin DSL
